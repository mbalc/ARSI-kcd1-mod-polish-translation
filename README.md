# Polskie tłumaczenie A Real Sorted Inventory

Nieoficjalne (jeszcze :v) polskie tłumaczenie tekstów moda
[**A Real Sorted Inventory (ARSI)**](https://www.nexusmods.com/kingdomcomedeliverance/mods/2204) do gry _Kingdom Come:
Deliverance_.

Autorem projektu i polskiego przekładu jest **mbalc**.

## Cel projektu

Przy korzystaniu z ARSI wraz z polską wersją gry - niektóre nazwy przedmiotów pojawiają się po angielsku wśród nazw
polskich, przez co nazewnictwo w ekwipunku staje się niespójne. Celem projektu jest przełożenie tekstów z szablonu ARSI
i zachowanie polskich nazw używanych już w grze tam, gdzie można potwierdzić ich odpowiednik. Tłumaczenie nie ma
zmieniać mechaniki sortowania.

## Stan

Repozytorium zawiera roboczy plik `text__ARealSortedInventory[1].xml`. Przekład nie jest ukończony, a gotowy pakiet ani
sprawdzona instrukcja instalacji nie są jeszcze dostępne. Zgłoszony problem nie został niezależnie odtworzony w grze.
